# Contributing

Thanks for your interest in WpfPilot MCP.

## Development

See [docs/development.md](docs/development.md) for clone, build, test, and project layout.

## Releases

See [docs/releasing.md](docs/releasing.md) for publishing Windows zips and the npm launcher.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Run `dotnet test WpfPilotMcp.sln` before opening a PR.
3. Keep changes focused; update docs when behavior or configuration changes.

## Questions

Open a [GitHub issue](https://github.com/skuzadev/wpfpilot-mcp/issues) for bugs and feature requests.
